# OpenSEO Desktop — instaladores

Instaladores da versão desktop **não oficial** do
[OpenSEO](https://github.com/every-app/open-seo) para Windows. Este repositório
guarda só os arquivos de instalação; o aplicativo consulta as
[releases](../../releases) daqui para avisar quando há versão nova.

## Instalar

Baixe o `OpenSEO Setup x.y.z.exe` da [última release](../../releases/latest) e
execute. A instalação é por usuário e não pede administrador. O instalador não
é assinado, então o Windows SmartScreen avisa na primeira execução
("Mais informações" → "Executar assim mesmo").

## Sobre

O OpenSEO é um projeto de código aberto da Every App, sob licença MIT. Esta
versão desktop é um trabalho derivado, sem vínculo com os autores originais.
